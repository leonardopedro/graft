List entries under a prefix

## Usage

```text
workspace entry ls [OPTIONS] [PREFIX]
```

## Arguments and options

| Argument or option | Default | Description |
| --- | --- | --- |
| <PREFIX> |  | Path prefix; the whole workspace when omitted |
| --all |  | Include soft-deleted entries |
