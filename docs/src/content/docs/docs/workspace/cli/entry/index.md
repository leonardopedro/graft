Read and write catalog entries

## Usage

```text
workspace entry <COMMAND>
```

## Commands

| Command | Description |
| --- | --- |
| [`put`](/docs/workspace/cli/entry/put/) | Insert or update an entry |
| [`get`](/docs/workspace/cli/entry/get/) | Print one entry |
| [`ls`](/docs/workspace/cli/entry/ls/) | List entries under a prefix |
| [`rm`](/docs/workspace/cli/entry/rm/) | Soft delete an entry |
