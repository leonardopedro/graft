Copy selected entries into a staging directory

## Usage

```text
workspace release stage --entry <ENTRIES> --out <OUT>
```

## Arguments and options

| Argument or option | Default | Description |
| --- | --- | --- |
| --entry <ENTRIES> |  | Catalog entry to include; repeatable |
| --out <OUT> |  | Staging directory; must be absent or empty |
